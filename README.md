# Customer Purchase Behavior Analysis using Hadoop and Apache Spark

## Overview

This project analyzes customer behavior using a large-scale e-commerce clickstream dataset containing approximately 67.5 million customer interaction records (~9 GB).

Apache Hadoop HDFS was used for distributed storage, while Apache Spark was used for data preprocessing and exploratory analysis. The project focuses on understanding customer activities, product categories, brand interactions, purchase behavior, and revenue trends.

## Dataset

- Dataset: E-Commerce Behavior Data from a Multi-Category Online Store
- Source: Kaggle
- Records: ~67.5 Million
- Size: ~9 GB
- Attributes: 9

## Technologies Used

- Hadoop HDFS
- Apache Spark
- Spark SQL
- Scala
- Linux

## Workflow

1. Store dataset in HDFS
2. Load dataset into Spark
3. Data preprocessing and cleaning
4. Missing value handling
5. Exploratory data analysis
6. Customer behavior analysis

## Analysis Performed

- Event type distribution
- Top brands analysis
- Top product categories
- Purchase transaction analysis
- Revenue analysis
- Most active users

## Future Enhancements

- Customer purchase prediction using Spark MLlib
- Classification models for purchase behavior
- Customer segmentation and recommendation analysis
